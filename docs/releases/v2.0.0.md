# Vibecheck 2.0.0 source development

This source version adds the shared work/activity service, semantic task targets, human operators, registered worktrees, host session collection, lifecycle, immutable artifacts, and recoverable observer notifications. Existing nine-tool requests and schema-v1 work history remain compatible.

Bun 1.3.14 or newer is the single application, development, test, and packaging runtime. Node runtime fallback and the duplicate Node test matrix have been removed. Built-in node: API imports remain supported by Bun. The release runtime targets Bun and uses bun:sqlite directly.

This file documents the source version. No 2.0.0 Git tag, marketplace release, or public release artifacts are claimed published by these implementation commits. Build local archives with bun run build:release and verify them with bun run verify:release.

See docs/work-activity.md for the observer API, explicit collector setup, attribution limits, storage and retention, and service-mode MCP configuration.
