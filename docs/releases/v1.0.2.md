# Vibecheck 1.0.2

This release removes personal commit-identity and agent-model instructions from `AGENTS.md`. The repository instructions, shared plugin skill, and both plugin archives were checked for copies of those directives. Author metadata in the package and plugin manifests is preserved.

The nine-tool protocol, runtime behavior, and SQLite schema are unchanged.

Install through the [Codex or Claude instructions](https://github.com/mgd34msu/vibecheck/blob/v1.0.2/README.md#install-the-plugin). This release includes both plugin archives, the standalone runtime archive, and `SHA256SUMS`.

Verification passed all 127 tests on Bun 1.3.14 and compiled JavaScript on Node.js 26.1.0. Both native plugins passed installation and MCP lifecycle checks from source and extracted archives.

Run `bun run verify` for source checks. Run `bun run build:release` and `bun run verify:release --native` to rebuild and verify the archives and native plugin installations.
